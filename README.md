# Emmanuel Chukwuma — Personal Portfolio

A responsive multi-page personal brand website.

## Pages
- **Home** — Introduction and overview
- **About** — Background, education, skills, interests
- **Projects** — Selected work with descriptions and images
- **Academic Planner** — Interactive task manager (add / complete / delete) with local storage
- **Contact** — Form with client-side validation

## Features
- Fully responsive (mobile-friendly)
- Light / Dark mode toggle (persisted)
- Semantic HTML
- External CSS with Flexbox & Grid
- JavaScript for interactivity, DOM updates, form validation, and task management
- Consistent professional colour scheme (blue accents, gray base, gold/red touches)

## How to run
Open `index.html` in any modern browser. No build step required.
